# GL.iNet Region Changer

### Смена региона Beryl AX с подсказками на русском

Пошаговый помощник для **GL.iNet Beryl AX / GL-MT3000** с китайским регионом. Помогает изменить заводской код CN, чтобы штатная панель могла отображать VPN и другие доступные в прошивке функции.

**Статус: 1.0.0-rc1. Автотесты пройдены; эта переработка ещё не проверена на настоящем роутере. До такой проверки продавцом не запускайте её как готовую клиентскую версию.**

> Понадобится сброс настроек: Wi-Fi, интернет, VPN и пароль администратора нужно будет настроить заново. Если вы уже настроили роутер, заранее сохраните нужные данные. Помощник работает с заводским разделом и не поддерживается GL.iNet официально; питание во время записи отключать нельзя.

Только **Beryl AX GL-MT3000 со штатной прошивкой GL.iNet**. Для других моделей и обычной OpenWrt эта версия не предназначена.

## 1. Подключитесь к Beryl

Подключите компьютер к роутеру по кабелю или его Wi-Fi. Подключите сам Beryl к интернету. Откройте [192.168.8.1](http://192.168.8.1) и задайте пароль администратора, если ещё не сделали этого.

На время работы оставьте роутер подключённым к стабильному питанию.

## 2. Откройте терминал

- **Windows 10/11:** нажмите `Win + R`, введите `cmd` и нажмите Enter.
- **macOS:** откройте приложение «Терминал».
- **Linux:** откройте ваш терминал.

Вставьте команду и нажмите Enter:

```sh
ssh root@192.168.8.1
```

Если вы меняли адрес роутера, используйте свой адрес вместо `192.168.8.1`.

При **первом подключении к своему роутеру** SSH может попросить подтвердить ключ: введите `yes` и нажмите Enter. Затем введите **пароль администратора панели роутера**, а не пароль Wi-Fi.

**При вводе пароля символы и звёздочки не появляются. Это нормально:** введите пароль и нажмите Enter. Не отправляйте пароль продавцу и не публикуйте его.

После подключения вы увидите строку наподобие `root@GL-MT3000:~#`. Следующая команда вводится именно здесь — уже на роутере.

## 3. Запустите помощник

Скопируйте **всю строку целиком**, вставьте в окно SSH и нажмите Enter:

```sh
d=$(mktemp -d /tmp/beryl-start.XXXXXX) && curl -fL --connect-timeout 15 --max-time 90 https://raw.githubusercontent.com/illegalFeed/GL.iNet-Region-Changer/main/beryl-region.sh -o "$d/beryl-region.sh" && printf '%s  %s\n' 2cbaed8a57c27164339dff6222f70f039645ec7ff944d6f7a826f4597664f0a9 "$d/beryl-region.sh" | sha256sum -c - && sh "$d/beryl-region.sh"
```

Команда скачивает одну фиксированную версию, проверяет контрольную сумму и запускает её. Если скачивание или проверка не удались, мастер не запустится. Автообновлений и загрузки кода из других репозиториев нет.

Дальше следуйте подсказкам в окне:

1. Помощник проверит модель и заводской раздел. Выберите регион: **Enter оставляет US**, как в исходном скрипте; также доступны RU, DE и GB. Это не выбор языка интерфейса.
2. Для подготовки введите `START`. На роутере будет создана резервная копия Factory, но регион пока не изменится.
3. Помощник покажет **готовую команду для сохранения копии на компьютер**. Оставьте первое окно открытым, откройте второе окно терминала на компьютере и выполните эту команду там. Дождитесь завершения копирования и проверьте, что файл появился на компьютере.
4. Вернитесь в первое окно. Введите `SAVED`, только когда копия сохранена. После этого помощник изменит два байта кода страны и проверит весь раздел.
5. После сообщения об успешной проверке введите `RESET`, чтобы сбросить настройки и перезагрузить роутер. Либо нажмите Enter, чтобы отложить сброс.

На любом шаге подтверждения **Enter без нужного слова означает отказ**. Сброс не выполняется автоматически после смены региона.

Копия нужна именно от **вашего** роутера. Храните её на компьютере; не публикуйте и не используйте копию другого устройства. При сбросе локальная копия на роутере удаляется.

## 4. Настройте роутер заново

После сброса SSH отключится, а Wi-Fi может пропасть — это ожидаемо. Дождитесь загрузки, снова подключитесь к Beryl и откройте [192.168.8.1](http://192.168.8.1).

Заново задайте пароль администратора и настройки интернета. Проверьте разделы VPN и AdGuard Home в панели. Смена региона не устанавливает отсутствующие компоненты и не обещает одинаковый набор функций на всех прошивках.

Если вы отложили сброс, выполните его позже в панели: **SYSTEM → Reset Firmware**. До сброса новые разделы могут не появиться.

## Если что-то пошло не так

| Что вы видите | Что сделать |
| --- | --- |
| `ssh` не распознана в Windows | Включите «Клиент OpenSSH» в дополнительных компонентах Windows или используйте PuTTY: SSH, адрес роутера, порт 22, логин `root`. |
| `Permission denied` при подключении | Используйте пароль администратора панели. Символы при вводе скрыты. |
| `Connection refused` / истекло время ожидания | Проверьте, что компьютер подключён к Beryl, адрес правильный, а SSH разрешён в настройках доступа панели. Не открывайте SSH в интернет. |
| Предупреждение об изменившемся ключе SSH | Оно возможно после сброса или при подключении к другому роутеру по тому же адресу. Не удаляйте старый ключ вслепую; сначала убедитесь, к какому устройству подключились. |
| Не удалось скачать файл, ошибка TLS или контрольной суммы | Ничего не запускайте вручную в обход проверки. Проверьте интернет и время на роутере; передайте продавцу текст ошибки. |
| Нет `curl`, `sha256sum`, `od` или другой команды | Не устанавливайте случайные пакеты. Передайте продавцу модель, версию прошивки и сообщение; можно перенести проверенный файл через SCP. |
| CN не найден / найдено несколько совпадений | Запись остановлена. Возможно, регион уже изменён или структура отличается. Отправьте продавцу текст ошибки и версию прошивки. |
| Ошибка **после начала записи** | Следуйте сообщению мастера: не сбрасывайте и не перезагружайте устройство. Свяжитесь с продавцом, сохранив заводскую копию. |

## Что делает помощник

Проверяет GL-MT3000, ищет однозначную сигнатуру CN в Factory, создаёт копию, меняет два байта и сравнивает результат с ожидаемым образом. Не меняет пароли, настройки Wi-Fi или прошивку при самой записи региона. Сброс настроек — отдельный шаг с подтверждением `RESET`.

Для предварительной проверки без записи скачанный файл можно запустить так:

```sh
sh /путь/к/beryl-region.sh --check
```
