# Происхождение и изменения

Основано на методе [Oasis-2023/glinet-remove-chinalock](https://github.com/Oasis-2023/glinet-remove-chinalock), файл `glinet-remove-chinalock.sh`, Git blob `30f1dba40315b84b96c8950d11db9f897f990eca` (получен 16 октября 2026).

Автор исходного кода: Aaron Viehl (Admon), copyright 2024. Лицензия MIT сохранена в [LICENSE](LICENSE). В исходнике также указан проект Admonstrator/glinet-remove-chinalock; автоматическая загрузка оттуда в этой версии отсутствует.

Из исходного метода сохранены поиск заводского раздела, признаки `firsttest`/`secondtest`, поиск `FF CN` или `00 CN` и изменение двух ASCII-байтов страны. Признаки не являются полной проверкой структуры или доказательством совместимости прошивки.

Клиентский сценарий, проверки, документация и тесты переработаны для GL-MT3000. Добавлены единый поиск двух сигнатур с отказом при неоднозначности, проверка размера и результатов чтения/записи, сравнение всего Factory с ожидаемым образом, блокировка параллельного запуска, обязательный шаг сохранения копии и отдельное подтверждение сброса.

Ни GL.iNet, ни автор исходного проекта не поддерживают эту модификацию официально. Исходный проект сообщает о проверке на GL-MT3000; это не означает, что текущая переработка испытана на устройстве. Статус этой версии — release candidate до проверки владельцем на реальном Beryl AX.
